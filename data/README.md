# UCI Heart Disease data

The accompanying `heart_disease.csv` contains the 303-record Cleveland subset fetched through the UCI Machine Learning Repository dataset 45 API. It contains 13 selected predictors and the original `num` outcome; missing predictor values remain blank for pipeline imputation.

**Dataset citation:** A. Janosi, W. Steinbrunn, M. Pfisterer, and R. Detrano, *Heart Disease*, UCI Machine Learning Repository, 1989. DOI: [10.24432/C52P4X](https://doi.org/10.24432/C52P4X).

**License:** Creative Commons Attribution 4.0 International (CC BY 4.0). Source: [UCI dataset page](https://archive.ics.uci.edu/dataset/45/heart+disease).

This is a historical, de-identified academic dataset. It is not a current clinical cohort and must not be used for diagnosis or patient care.
